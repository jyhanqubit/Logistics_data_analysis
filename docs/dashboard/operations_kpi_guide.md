# Operations KPI Guide

OMS/WMS/TMS KPI는 공개 물동량 데이터를 기반으로 생성한 simulation layer에서 계산됩니다.

## OMS
- order_count, order_to_release_lead_time, cancellation_rate, backorder_rate, peak_order_ratio

## WMS
- inventory_turnover, stockout_risk_score, picking_productivity, warehouse_utilization, pick_pack_cycle_time

## TMS
- on_time_delivery_rate, vehicle_utilization, route_distance, cost_per_delivery, late_delivery_risk_score
