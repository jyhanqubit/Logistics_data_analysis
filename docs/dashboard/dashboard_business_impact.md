# Dashboard Business Impact

이 대시보드는 공개 생활물류 데이터를 기반으로 만든 분석 결과를 경영/운영 관점으로 해석하기 위한 화면입니다.

핵심 질문:
1. 어떤 지역/카테고리에서 물동량이 증가하는가?
2. 예측 정확도는 baseline 대비 충분히 개선되었는가?
3. 거점/락커 추천이 SLA/비용 관점에서 타당한가?
4. 경로 최적화와 QUBO formulation이 운영 의사결정에 어떤 통찰을 주는가?
5. OMS/WMS/TMS KPI를 통해 운영 리스크를 어떻게 조기 탐지할 수 있는가?

주의:
- 내부 기업 원천시스템 데이터로 해석하지 않는다.
- 운영 이벤트는 공개 수요 데이터 기반 simulation layer이다.
